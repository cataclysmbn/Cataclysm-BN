# Stable 0.1

## ゲームプレイ

- 勝利条件: <details><summary>ネタバレ</summary>オーバーマップの (0'0, 0'0) から (0'179, 0'179) までの長方形領域のどこかに中央研究所があります（z = -1 の「access shaft」というタイルから入れます）。最下層には赤い「L」タイルがあります。研究所を見つけて最下層に到達し、自分の命を犠牲にするかミニニュークを投入してください。</details>
- （現在も作業中ですが、すでに機能します）車両を使わない電力網システム。ただし車両に接続できます。詳しくは[電力網のページ](../../mod/json/explanation/electric_grids.md)を参照してください。
- 低い高度レベル（z レベル）が描画されるようになりました。
- 斜め向きの車両の、通常は通り抜けられない壁に「穴」が開かなくなりました。これはモンスターやプレイヤーの移動、視線計算、光と匂いの伝播など、関連するすべてのゲームメカニズムに影響します。
- ヘリコプターを再設計:
  - すべてのキャラクターと職業がヘリコプターを使えるようになりました
  - 既存のヘリコプターからブレードを回収すれば、ヘリコプターを製作できます
  - ヘリコプターの燃料消費を減らし、ゲーム内時間で数時間飛行できるようにしました
  - ローターが衝突で壊れなくなりました
  - 原子力ヘリコプターを追加しました
- 遠距離攻撃全般:
  - 連射を再設計しました。全弾が同じ命中精度で発射され、すべてに反動依存のペナルティがかかります。大半の銃ではペナルティは分散と同程度で、軽い銃では 0 の場合があります
  - ヘッドショットをダメージ 150% のクリティカルに変更（200% 超から減少）。かすり傷のような命中は 50% に変更（0～25% から増加）
  - 一部のショットガン弾薬が円錐状の範囲攻撃を行うようになりました
- 弓とクロスボウ:
  - ステータスを強化（クロスボウは弓より大幅に強化）
  - クロスボウを作りやすくしました
  - 対象の HP に依存する特殊処理を削除しました
- 薬物をおおむね弱体化前の性能に戻しました
  - メタンフェタミンは例外で、長時間（12 時間）持続する弱い（速度 5、知覚 1）強化を与え、眠気を防ぎます
  - 薬物による士気上昇が薬物効果と同じ長さ持続するようになりました
- つかみ:
  - つかみと痛みのペナルティが重なりにくくなりました
  - つかんでいる敵に物理ダメージを与えると、つかみが外れることがあります（最大 HP の少なくとも 10% のダメージなら確率 100%）
  - つかみがブロックに影響せず、回避への影響も大幅に減りました
  - つかみ攻撃が速くなり、命中すると無料の通常攻撃が続きます
- 範囲攻撃（斧、槍、ラジャタンによるもの）から必要条件を削除しました
- 息切れ状態を削除しました
- 爆発物を再調整: 射程を短くし、爆風ダメージを 100%/50%/0% に丸め、破片は距離に依存しないダメージを正確に 1 回だけ与えます
  - 「Rule Of Cool explosions」デバッグ設定: 爆発は視線の通る地形と生物にのみダメージを与えるため、角の後ろに隠れることが実際に有効になりました
- 爆発物、車輪、弾丸がアイテムを傷つけなくなりました。十分に強い爆発なら破壊でき、3 種類すべてが蘇生可能な死体を粉砕します
- 火の累積を減らし、火炎放射器がプレイヤーに与えるダメージを軽減しました
- 変異:
  - 特性コストを実際の影響により正確に合わせて再調整
  - 戦闘変異（鎧、爪）を改善
  - キャラクター作成から「無料ポイント」特性（熟睡者、嘘つきなど）を一部削除
  - 指向性のない変異がまとめて発生し、その数が前回の変異からの経過時間に基づくようになりました
  - ほとんどの悪い変異が良い変異より悪いことを補うため、変異はポイント上「開始時より少し良い」方向に傾きます
  - 変異毒素を再設計。十分に蓄積すると変異を起こしますが、ペナルティは発生しません
- CBM のインストールは必ず成功しますが、その後に失敗効果が発生することがあります。そのため、手術に失敗しても実用可能な状態のバイオニックがプレイヤーに与えられます。CBM の取り外しは依然として完全に失敗することがあります。オートドックは手術失敗でプレイヤーを即死させず、代わりに致命的なダメージではなく感染を起こします。手術失敗時に体へ与えるダメージは、バイオニックのインストール難易度の影響を受けるようになりました
- タレットが音を立てない攻撃者に反撃しますが、射程外の攻撃者には反撃しません。コードがタレットのステータスとスキルをより適切に尊重するようになりました
- 手術で応急手当を訓練できるようになりました。対象の大きさと装着可能なバイオニックの数に応じて上昇します
- 食料:
  - 肥満の仕組みと胃に関する仕組みの大部分を削除
  - 満腹状態から餓死するまでの時間を 1 週間に変更
  - 睡眠中の空腹・渇きの減少を削除
- 動物の排泄物の仕組みを削除
- 破傷風、ランダムな風邪、インフルエンザを削除
- 真菌の胞子が真菌人間を生み出さなくなり、真菌病が腕を折らなくなりました
- 食料の温度の仕組みを再設計。「柔らかい」仕組みを削除しました。腐敗は引き続き温度の影響を受けます。冷凍庫は意図どおり機能して腐敗を防ぎ、火は体を温めます

## 生活の質

- 製作はデフォルトでインベントリまたは地面から行われ、範囲内で最も良い作業台が自動的に使われます
- 地面や車両内などのアイテムを読めるようになりました。読書で本が自動的に拾われず、その場に残ります
- 製作中に残り時間と製作補正を表示
- 解体で製作範囲内の道具を使い、問題を警告
- 展開可能な解体家具に展開が不要になり、アイテム状態でも使えるようになりました
- 以前インベントリになかったアイテムを、荷降ろし時にインベントリへ移さなくなりました
- AIM（高度インベントリ管理）でアイテムを z レベル間で上下に移動可能
- （射撃やリーチ攻撃中の）対象リストで、窓越しや車両の上（タレットから）を撃てるようになりました
- 盲目でない場合、少なくとも 1 タイルの視界が保証されます
- タイル記憶が減衰しなくなりました
- スキル、バイオニック、着用による負担など、すべての補正を含む正確な銃器の分散・反動ステータスを追加

## 新コンテンツ

- デバフに重点を置いた医療ゾンビの系統
- CROWS 型に代わる新しい自動銃タレット。殺傷力は低いものの、価値のあるライフル弾を大量に落としません
- 解体する価値のある死体を検出するバイオニックスキャナー

## パフォーマンス

- 火が熱気や煙を生み出さず、風の影響も受けなくなりました
- イベントバスシステムを無効にするオプション（デバッグタブ）を追加。大きなサイクル負荷を除去しますが、実績と統計も無効になります
- 食料が放射熱や熱気の影響を受けなくなりました
- Magiclysm だけに有益で、全員を遅くしていた遅い fd_clairvoyant チェックを削除
- 3D モードでは取得が遅いため、マップ上の全車両リストをキャッシュ
