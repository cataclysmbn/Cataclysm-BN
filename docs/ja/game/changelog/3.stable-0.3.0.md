# Stable 0.3

## ゲームプレイ

- 新シナリオ: 野生人（Feral）としてプレイし、特定の条件下でゾンビと友好的な関係を築けます。
- 電圧計といくつかの材料を使って、複数の電力網を手動で接続・切断できるようになりました。
- ゲームに盾を追加。
- Rule of Cool 爆発をさらに改善:
  - 連鎖爆発
  - アイテムが破片になる
  - カスタムアニメーション

## バランス

- メックを改善。
- 製作可能なヘリコプター用ローターを追加。
- 放水砲が酸を発射できるようになりました。
- 浄水方法を改善。
- 弓をさらに調整（ダメージを減少、筋力上限をソフトキャップに変更）。
- パワーアーマーの出現場所を調整。

## 新コンテンツ

- 新しい CBM を追加。一部の CBM は既存 Mod から移植されています。
- 多数の場所を再設計・改善。
- Old Guard 派閥を拡張。

## インフラ

- 研究所のフィナーレを再設計。
- ビルドファイルを更新。
- 武術と銃器 Mod 用の武器カテゴリを追加（Mod 統合を容易にするため）。
- NPC がハードコードされた一覧だけでなく、すべてのバイオニック武器を使えるようにしました。
- NPC の攻撃方法のコードを改善し、武器と攻撃をより適切に選べるようにしました。マガジンを再装填し、単発武器で戦闘再装填を行えるようになりました。

## バグ修正

- NPC の AI による武器選択と遠距離攻撃に関する複数のバグを修正。
- オフロード車両の動作を修正。
- Mod を有効にしすぎるとオーバーマップの特殊地点がすべて生成されない長年の問題を修正。
- モンスターの攻撃と z レベル間の移動を修正。

## 後のバージョンの DDA からの移植

- 野生の人間（追加調整あり）。
- 追加の実績。
