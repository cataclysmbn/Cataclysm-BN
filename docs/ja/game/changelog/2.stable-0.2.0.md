# Stable 0.2

## ゲームプレイ

- テレグロー、ネザーへの関心、凝視によるモンスター攻撃を再設計。
- AI が移動中の車両を標的にして射撃できるようになりました。
- 食料アイテムに、温度が腐敗へ与える影響が表示されるようになりました。
- グラフィカルオーバーマップがデフォルトで有効になりました。古い Graphical Overmap Mod を廃止し、Larwick's Overmap に改名しました。
- Mod リソースを再編成しました。Bright Nights の全リソースに固有 ID が付くようになりました。
- ランプの上へ車両を押せるようになりました。
- 近接スキルが攻撃時のスタミナ消費に実際に影響するようになりました。
- マルチドロップメニューでアイテムをお気に入りに登録できるようになりました。

## バランス

- 弾薬と防具を全面的に再調整しました。徹甲弾が装甲目標に対してより有効になり、防具は場合によって銃弾に少し強くなりました。パワーアーマーのステータスも再設計されています。
- 鍛造フレームに必要だったまぶしさ防止を削除。
- 自転車の発電機（ダイナモ）を製作可能にしました。
- 鍛造でアイテムを修理できるようにしました。
- 一部パーツの取り付け・取り外しを簡単にしました。
- ロボットがレーザーに完全免疫ではなくなりました。
- 回避スキルを得るための悪用方法を防止。
- レイスとシャドウの特殊攻撃を更新。
- Arcana のシャドウとカルト生物を更新。
- ミーゴの位置と待機フィールドを調整。

## 生活の質

- ゲームから直接バグレポートを送信できるようになりました。
- 点滅効果の速度を低下（300 → 800ms）し、ゲーム内で変更できるオプションを追加。
- ペットメニューからペットロボットを無効化できるようになりました（クエリを使わなくなりました）。
- 飛行中に操作を手放したとき、または運転を停止したときに警告を表示。

## インフラ

- C++17 へ移行。
- アーティファクトの再充電を実装。
- グリッド建築物が作業場カテゴリを使うようになりました。
- 建築レシピをお気に入りに登録でき、建築 UI で名前順に並べられるようになりました。

## 新コンテンツ

- 新しい電力網家電を追加。
- グリッド鍛造設備、化学セット、化学実験室を追加。
- 運搬ロボットを追加。
- 大半の建物に内蔵電力網が含まれるようになりました。
- 特に Mod 用に、より多くの場所へグリッドフラグを追加。
- ヘリパッドに新しいヘリコプターパーツ群を追加。
- 取り付け可能なオートドックとオートドックソファを追加。

## 後のバージョンの DDA からの移植

- 完全な首輪・リードシステムを移植。
- 呪文を唱えるモンスターと召喚呪文への修正を移植。
- DinoMod を更新。
- ゲーム内の進行日誌を追加。
- 大聖堂を改修。
- biker_dump に NPC を追加。
- Barbaran Montante を移植し、再調整。

## その他

- 死亡リストと自殺に、欠落していたダメージ源によるキルを追加。
