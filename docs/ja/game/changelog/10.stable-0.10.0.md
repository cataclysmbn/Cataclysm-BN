# Stable 0.10

この概要は、このリリースで最も重要な変更を列挙したものです。このリリースには、機能とバグ修正を含む 188 件の変更があります。

## ゲームプレイ

- NPC の取引と会話インターフェースを再設計し、返答の選択とインタラクションの流れを改善
- 初期特性の浄化と取り消しのためのワールド設定を追加
- 木登りで滑ることがあり、強い衝撃を受けると生存者が不安定な地面から落ちるようになりました
- 車両のアイドルリフトが抗力を減らし、地面の高さで浮上できるようになりました
- 車両タレット用の自動装填装置を追加

## 新コンテンツ

- 非正方形のネストマップ生成に対応した貨物船オーバーマップ特殊地点を追加
- MST Extra のコンテンツをコアゲームに移植
- 車両建造用のアルミ製ボート船体と木製の翼タイルを追加
- GUNSHY と Nyctophobia の特性を追加
- 銃器の付与効果と娯楽用家具の建築を追加

## バランス

- ミニニュークのダメージを 300 から 3000 に増加
- CBM の身体スロットコストを再調整し、マイクロリアクターの動作を原子力バッテリーの流れに合わせて変更
- プルトニウムセルを時間経過で自己充電するよう再設計し、バッテリー区画が軍用プルトニウム燃料セルを収容できるようにしました
- 中世防具の素材を調整して防護を向上し、自動装填装置の電力消費を 50 kJ から 5 kJ に減少
- 拡張ツールセットを廃止し、修理と焼灼の機能を統合ツールセットへ移動

## インフラ

- Android がユーザーからアクセス可能な Mod ディレクトリを使うようになりました
- 弾丸と投擲アイテムのスプライトを JSON でカスタマイズできるようになりました
- アイテム変数を JSON で定義できるようになりました
- Lua が、拡張された NPC と会話フックに加えて、適切な相対・絶対 require パスをサポートするようになりました
- 保存形式 v2 が現行となり、v1 はレガシーとして扱われるようになりました

## バグ修正

- 飛行ロボットを再びハッキングできるように修正
- 訓練活動でのクラッシュを修正
- Mycus の果実を食べたときのクラッシュと、Mycus キャラクターをソフトロックする可能性のある進行不能を修正
- 燻製ラックと炭焼き窯の読み込み時にアイテムが消える問題を修正
- 車両のはしごが取り付け順に依存せず機能するように修正

## DDA からの移植

- シナリオを含む relentless hulk と NEMESIS のコンテンツセットを移植
- 基本難易度チェックを削除する指向性トラップ解体の変更を移植

完全な変更履歴は[こちら](https://github.com/cataclysmbn/Cataclysm-BN/releases/tag/v0.10.0)を参照してください。
