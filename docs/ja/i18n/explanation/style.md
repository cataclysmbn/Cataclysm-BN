# 言語別スタイルガイド

> [!NOTE]
>
> #### 本セクションはテンプレートです。
>
> このページは言語固有の注記を記載するためのものなので、このセクション自体を翻訳する必要はありません。
> 代わりに、このページをテンプレートとして使用してください。[言語固有の記述スタイルガイドの例はこちら](#ご自身の言語の記述スタイルガイド)で確認できます。

## 言語固有のスタイルガイドを作成する方法

1. [言語コードを確認します](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes)。
2. `/docs/{your-language-code}/i18n/explanation/style.md` を作成します。
3. 言語がまだ設定されていない場合は、`docs/plugins/languages.ts` ファイルに言語コードを追加します。例：

```diff
-export const languages = ["en", "ko", "ja", "ru", "de"]
+export const languages = ["en", "ko", "ja", "ru", "de", "fr"]
```

この例では、フランス語がドキュメントサイトで利用できるようになります。

## ご自身の言語の記述スタイルガイド

このファイルに何をどのように記述するかについて、制限はありません。たとえば、以下のような記述が可能です。

- 他の翻訳者が読むための、言語固有の注記を記述する
- 外部リソースやツールへのリンクを貼る

参考として、既存のスタイルガイドを確認できます：

- [Deutsch](../../../de/i18n/explanation/style.md)
- [Русский](../../../ru/i18n/explanation/style.md)
