# オプション

## オプショングループ

オプションメニューに新しいグループを追加します。

| キー    | 説明                                                                                                |
| ------- | --------------------------------------------------------------------------------------------------- |
| `type`  | 常に `OPTION_GROUP`。                                                                               |
| `id`    | グループの ID。                                                                                     |
| `page`  | `general`、`interface`、`graphics`、`performance`、`world_default`、`debug`、`android` のいずれか。 |
| `title` | 表示するオプション名。                                                                              |
| `desc`  | 詳細なオプションの説明。                                                                            |

## オプションスペース

オプションメニューに新しいスペースを追加します。

| キー   | 説明                                                                                                |
| ------ | --------------------------------------------------------------------------------------------------- |
| `type` | 常に `OPTION_SPACE`。                                                                               |
| `page` | `general`、`interface`、`graphics`、`performance`、`world_default`、`debug`、`android` のいずれか。 |

## オプション

オプションメニューにオプションを追加します。

| キー              | 説明                                                                                                                                                              |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `type`            | 常に `OPTION`。                                                                                                                                                   |
| `id`              | 一意のオプション ID。                                                                                                                                             |
| `stype`           | オプションの種類。                                                                                                                                                |
| `page`            | `general`、`interface`、`graphics`、`performance`、`world_default`、`debug`、`android` のいずれか。                                                               |
| `group`           | 所属させる任意のグループ ID。                                                                                                                                     |
| `menu_text`       | オプションの値として表示するテキスト。                                                                                                                            |
| `tooltip`         | オプションに表示する追加情報。                                                                                                                                    |
| `default`         | デフォルト値。                                                                                                                                                    |
| `default_android` | Android でのデフォルト値。                                                                                                                                        |
| `min`             | 整数・浮動小数点数の最小値。                                                                                                                                      |
| `max`             | 整数・浮動小数点数の最大値。                                                                                                                                      |
| `step`            | メニューで浮動小数点数に使う刻み幅。                                                                                                                              |
| `hide`            | `none`、`always`、`sdl_hide`（SDL 使用時）、`curses_hide`（curses 使用時）、`no_sound_hide`（サウンドなし）、`android_only`（Android 以外）で非表示を指定します。 |
| `deps`            | 設定に使う `option`（他のオプション ID）と `values`（有効なオプション値）の配列。                                                                                 |
