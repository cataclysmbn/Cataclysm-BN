---

### ネストされたレシピカテゴリ

ネストされたカテゴリを使用すると、クラフト UI 内に階層的なグループを作成できます。これは `type: "nested_category"` を持つ JSON オブジェクトで、レシピのように一覧表示・フィルタリングできますが、アイテムは生成しません。ネストされたカテゴリは折りたたみ可能な項目として表示され、レシピ（または別のネストされたカテゴリ）に展開されます。`nested_category_data` に記述します。

新しいクラフトタブを追加せずにグループ化の階層を増やしたい場合や、サブカテゴリの項目が多すぎる場合に使用してください。

### フィールド

| 識別子                 | 説明                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| `id`                   | ネストされたカテゴリの一意の ID。                                                                    |
| `type`                 | `nested_category` でなければなりません。                                                             |
| `nested_name`          | クラフト UI に表示する名前。ネストされたカテゴリには `result` がないため、指定することを推奨します。 |
| `category`             | 項目を表示するクラフトカテゴリ（`CC_*`）。                                                           |
| `subcategory`          | 項目を表示するクラフトサブカテゴリ。                                                                 |
| `description`          | クラフト UI に表示する任意の説明。                                                                   |
| `nested_category_data` | この項目の下に表示するレシピ ID またはネストされたカテゴリ ID の配列。                               |

### 動作に関する注意

- `nested_category_data` では、レシピ自身の ID で通常のレシピを、`id` で別のネストされたカテゴリを参照できます。レシピ ID は `id_suffix` 適用後の生成アイテム ID ではありません。
- ネストされたカテゴリに `result`、コンポーネント、工具、時間を定義しないでください。UI 専用の項目であり、製作できません。
- ネストされたカテゴリ間の循環参照は避けてください。循環は UI 表示時に無視され、項目が隠れることがあります。

### 例

```json
[
  {
    "type": "nested_category",
    "id": "hot_drinks",
    "nested_name": "hot drinks",
    "category": "CC_FOOD",
    "subcategory": "CSC_FOOD_DRINKS",
    "description": "Warm beverages and infusions.",
    "nested_category_data": [
      "coffee",
      "tea",
      "herbal_tea"
    ]
  }
]
```
