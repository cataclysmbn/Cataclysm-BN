# Mod の互換性

## 説明

データフォルダのルートにある `mod_interactions` フォルダには、特別な読み込み処理があります。このフォルダ内に Mod ID と同名のフォルダを置いてください。そのフォルダ内の内容は、もう一方の Mod が読み込まれた場合にのみ読み込まれます。このフォルダの内容は両方の Mod が読み込まれた後、通常の読み込み順で読み込まれます。

## 例

たとえば、Mod 1 が Arcana で、ルートに `mod_interactions` フォルダがあるとします。その中に `crt_expansion` フォルダを作ります。`crt_expansion` が読み込まれると、`professions.json` などのファイルがすべて読み込まれ、C.R.I.T. Anomaly Investigator が追加されます。

## 注意

入れ子になった Mod 間の相互作用には現在対応していません。Mod A と Mod B の両方がある場合に読み込むことはできません。

Mod A または Mod B のどちらかがある場合に読み込む、といった指定もできません。

Mod のソースはベース Mod です。
