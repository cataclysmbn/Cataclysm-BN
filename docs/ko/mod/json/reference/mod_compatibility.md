# 모드 호환성

## 설명

데이터 폴더 루트의 `mod_interactions` 폴더에는 특별한 로딩 규칙이 적용됩니다. 그 폴더 안에 모드 ID와 같은 이름의 폴더를 만드세요. 해당 폴더 안의 내용은 다른 모드가 로드된 경우에만 로드됩니다. 이 폴더의 내용은 두 모드가 모두 로드된 뒤 표준 로드 순서에 따라 로드됩니다.

## 예시

예를 들어 모드 1이 Arcana이고 루트에 `mod_interactions` 폴더가 있다고 합시다. 그 안에 `crt_expansion` 폴더를 만듭니다. `crt_expansion`이 로드되면 `professions.json`과 같은 모든 파일이 로드되어 C.R.I.T. Anomaly Investigator를 추가합니다.

## 참고

중첩된 모드 상호작용은 현재 지원되지 않습니다. 모드 A와 모드 B가 함께 있을 때만 로드하도록 만들 수 없습니다.

모드 A 또는 모드 B 중 하나가 있을 때 로드하는 방식도 지원되지 않습니다.

모드 소스는 기본 모드입니다.
