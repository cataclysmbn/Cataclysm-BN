### 아이템 카테고리

인벤토리를 카테고리별로 정렬하면 다음 카테고리가 표시됩니다.

| 식별자           | 설명                                                                                                                                                                                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`             | 고유 ID입니다. 하나의 연속된 단어여야 하며 필요하면 밑줄을 사용합니다.                                                                                                                                                                                                   |
| `name`           | 카테고리 이름입니다. 인벤토리를 열었을 때 게임 안에 표시됩니다.                                                                                                                                                                                                          |
| `zone`           | 대응하는 loot_zone입니다(`loot_zones.json` 참조).                                                                                                                                                                                                                        |
| `sort_rank`      | 표시할 때 카테고리를 정렬하는 데 사용합니다. 값이 낮을수록 먼저 표시됩니다.                                                                                                                                                                                              |
| `priority_zones` | 설정하면 조건이 맞을 때 이 카테고리의 아이템을 우선 구역으로 정렬합니다. 사용자의 구역 관리자에 우선 구역이 없으면 `zone` 속성에 지정한 구역으로 정렬합니다. 객체 배열이며 각 객체에는 LOOT_ZONE의 ID(`LOOT_ZONES.json` 참조)인 `id`와 플래그 배열인 `flags`가 있습니다. |

```json
{
  "id": "armor",
  "name": "ARMOR",
  "zone": "LOOT_ARMOR",
  "sort_rank": -21,
  "priority_zones": [{ "id": "LOOT_FARMOR", "flags": ["RAINPROOF"] }]
}
```
