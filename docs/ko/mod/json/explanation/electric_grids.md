# 전력망

전력망은 건물 안의 전기 연결입니다. 차량의 모든 부품이 배터리 전력을 공유하는 것과 비슷합니다.

# 기능

현재 전력망과 상호작용하는 가구는 다음과 같습니다.

- 장착형 태양광 패널(대피 센터 지붕의 패널 등): 에너지를 생산합니다.
- 장착형 배터리: 에너지를 저장합니다. 조사하면 해당 배터리와 전체 전력망의 전력량을 확인할 수 있습니다.
- 배터리 충전기: 차량 배터리 충전기/충전소처럼 작동합니다. 충전식 배터리나 이를 포함한 아이템을 충전기에 넣으면 장착형 배터리에서 전력을 가져와 충전합니다.
- 전압계: 전력망 연결을 확인하고, 저장된 에너지량을 확인하며, 전력망 연결을 확장할 수 있습니다.
- 오븐: 핫플레이트처럼 작동하지만 전력망의 충전량만큼 충전량을 가집니다.
- 점퍼 케이블 커넥터: 차량을 전력망에 연결합니다. 점퍼 케이블을 차량에 연결한 뒤 커넥터에 연결하면 대부분의 용도에서 차량과 전력망이 전력을 공유합니다. 다만 보통은 커넥터를 통해 보내기 전에 각자의 배터리를 먼저 충전하거나 방전합니다.
- 냉장고
- 바닥 램프
- 전기 가마
- 식품 탈수기
- 식품 가공기
- 진공 포장기
- 아크 용접기
- 전기 단조기
- 전기분해 키트

# 전력망 크기

전력망에서 건물은 오버맵 타일로 구성됩니다(지도에서 `M` 키를 눌렀을 때 보이는 타일이며, 지역 지도에서는 24x24 타일입니다). 대부분의 도시 건물은 개별 전력망을 가집니다. 예를 들어 지붕에 태양광 패널, 바닥에 오븐, 지하실에 배터리가 있는 집에서는 패널로 충전한 배터리의 에너지로 오븐을 사용할 수 있습니다. 건물이 없는 오버맵 타일은 자기 오버맵 타일 안에만 전력망을 가집니다. 현재 두 개의 커넥터, 두 개의 점퍼 케이블, 차량을 사용하는 방법 외에는 전력망끼리 연결할 수 없습니다.

# 모딩

전력망으로 가짜 아이템에 전력을 공급하는 가구를 만들려면 `"USES_GRID_POWER"` 플래그가 있는 가짜 아이템을 만들고 가구의 `"crafting_pseudo_item"`을 그 아이템의 ID로 설정합니다. 예를 들어 오븐 아이템은 다음과 같습니다.

```json
{
  "id": "fake_oven",
  "copy-from": "fake_item",
  "type": "TOOL",
  "name": { "str": "oven" },
  "sub": "hotplate",
  "max_charges": 1000,
  "flags": ["USES_GRID_POWER"]
}
```

오븐 가구에는 다음과 같이 사용합니다.

```json
"crafting_pseudo_item": "fake_oven"
```

현재 전력망은 가구의 일부로 사용되는 가짜 아이템에만 전력을 공급할 수 있습니다.

# 전력망 수동 추가(맵 설계용)

**경고: 이것은 맵 설계를 위한 방법입니다. 파일을 편집하지 않아도 게임 안에서 전력망을 만들 수 있습니다. 태양광 패널과 배터리를 설치하면 됩니다. 점퍼 케이블과 커넥터로 전력망을 차량에 연결할 수 있습니다.** 새 집을 만들면 그 집에는 전력망이 없습니다. 새 집에서 전력망을 사용하려면 게임의 저장 폴더에 있는 오버맵 파일을 가져와 편집해야 합니다. 파일 이름은 `o.0.1`과 비슷합니다. 필요한 내용은 다음과 같습니다.

```json
"electric_grid_connections":[[[0,0,0]], ... ... ... ]}
```

이 위치에 좌표를 추가합니다. 집이 `0'113, 2'56`에 있다면 오버맵 파일은 `o.0.2`이고 추가할 좌표는 `[113,56,0]`(또는 해당 z 좌표)입니다. 서로 다른 층을 연결하려면 다음처럼 좌표를 추가합니다.

```json
"electric_grid_connections":[[[113,56,0],[0,0,1]],[[113,56,1],[0,0,-1]]... ... ... ]}
```

`[0,0,1]`은 이 좌표가 위쪽 계단과 전력을 공유한다는 뜻이고, `[0,0,-1]`은 그 반대입니다. 집이 사무실 타워나 시청만큼 크다면 `[0,1,0]` 또는 `[1,0,0]`도 사용할 수 있습니다. 대형 건물의 전력망이 실제로 이렇게 작동합니다.
